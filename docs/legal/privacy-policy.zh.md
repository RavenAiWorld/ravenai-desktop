本政策说明 Ravenai 在提供网站、账号、API 接入及用量管理服务时可能处理的信息。运营主体及联系方式以运营方公布的信息为准。模型、登录及其他第三方服务可能另有适用的隐私规则。

## 一、适用范围

本政策适用于 Ravenai 提供的相关服务。您选择的第三方模型、认证服务或兼容工具，其独立开展的信息处理活动还应以该第三方的说明为准；这不免除平台对自身处理活动依法承担的责任。

## 二、我们处理的信息

根据您使用的功能，平台可能处理：

- 账号邮箱、账号标识、认证信息和您选择的第三方登录返回的必要资料，用于登录、账号安全及服务通知；
- API 密钥关联信息、调用时间、模型、用量、错误及安全记录，用于鉴权、用量管理、限流、故障排查和安全维护；
- 您发送的提示词、对话、代码、图片、文件或其他请求内容，以及生成结果，用于完成模型调用并返回结果；
- IP 地址、设备或浏览器信息以及网络访问记录，用于通信、风险识别和服务维护；
- 与使用服务相关的业务记录，以及您主动提供的联系沟通信息，用于处理咨询、权益请求和异常核查。

请只提交完成任务所必需的数据，不要在提示词或联系信息中发送密码、验证码、完整 API 密钥或不必要的敏感资料。涉及他人个人信息时，您应具有合法处理依据和必要授权。

## 三、请求、日志与上游处理

为完成模型调用，平台及您选择的上游服务需要处理请求内容。具体内容是否保存、保存位置和期限，取决于所使用的功能、实际配置及上游规则。平台不会仅凭“API 中转”承诺所有请求均不留存，也不统一承诺所有上游均不会使用数据进行训练。

如您对数据隔离、留存或模型训练有特定要求，请在提交数据前通过服务联系渠道确认实际安排。请勿提交国家秘密、无权披露的商业秘密或未经合法授权处理的敏感个人信息；必要时应进行脱敏。

## 四、Cookie、浏览器存储与安全验证

网站可能使用 Cookie 或浏览器本地存储维持登录、保存界面偏好和协议确认。协议确认记录保存在当前浏览器，清除数据、更换浏览器或协议内容更新后，可能需要重新确认；这不代表平台已建立与账号绑定的同意记录。

为识别自动化滥用并保护登录、注册等流程，平台使用 Cloudflare Turnstile 进行人机验证。验证过程中，浏览器会与 Cloudflare 通信，可能涉及 IP 地址、浏览器或设备信号及验证结果等必要信息。相关处理还受 Cloudflare 的隐私说明约束。安全验证不替代依法需要单独取得的授权或同意。

## 五、信息共享、存储地点与跨境传输

### 5.1 信息共享

为提供您选择的功能，必要信息可能传递给模型或上游接口供应商、服务器和网络服务商，以及认证、安全验证等服务商。平台将根据实际处理关系和适用法律，履行必要的告知、授权及保护义务，并在必要范围内提供信息。

为履行法定义务、响应合法要求或处理安全事件，平台也可能在必要范围内提供相关信息。

### 5.2 存储地点与跨境传输

个人信息的存储地点及接收方所在地，以具体服务实际部署和相关告知为准，可能位于您所在国家或地区以外。

**如使用境外模型或其他境外服务需要向境外提供个人信息，我们将依法履行相应告知、单独同意及适用的跨境合规义务。不会仅以您发起调用或接受本政策，替代依法需要履行的程序。**

具体涉及的接收方、处理目的、信息种类、处理方式及权利行使渠道，应按实际服务和适用要求另行告知。本政策不表示所有服务均具有相同的部署地点或跨境安排。

## 六、保存期限与信息安全

账号资料、调用记录、服务记录和备份可能具有不同的保存期限，具体取决于实际配置、服务需要及法定义务。平台将遵循必要原则处理信息，并在符合条件时删除或匿名化；依法需要留存或仍有待处理事项的信息可能不能立即删除。

平台采取与实际风险相适应的访问控制、传输保护和维护措施，但任何系统均不能保证绝对安全。请妥善保护账号凭据和密钥；如发现异常，应及时停用受影响凭据并联系平台。

如发生适用法律要求通知的安全事件，平台将依法采取相应处置和通知措施。

## 七、您的权利与联系方式

在适用法律规定的范围内，您可以申请访问、更正、删除或获取您的个人信息副本，限制或反对某些处理，或撤回基于同意的授权。撤回同意不影响撤回前基于同意已开展处理的合法性；某些信息可能因法定留存或尚未解决的事项而不能立即删除。

请通过平台公布的服务联系渠道提出请求，并说明账号及事项。为保护账号安全，平台可能要求合理的身份核实；请勿发送密码、验证码或完整密钥。您也可以依法向有权机构提出投诉。

## 八、未成年人保护与政策更新

不具备独立使用资格的未成年人，应在适用法律及监护人要求允许的情况下使用服务。如发现不当处理未成年人信息，可联系运营方核查；涉及依法需要监护人同意的处理，应按相应要求履行程序。

政策有重大变更时，平台将通过站内信息等合理方式提示，并在适用法律要求时重新征求同意。接受本政策不替代法律要求另行履行的告知、单独同意或其他程序。
